<details-utils> Web Component

A suite of utilities to add more features to the <details> element.

Source @zachleat/details-utils on npm npmx Blog Post All Projects

Go back to the GitHub repository.

To use, wrap one (or more!) <details> elements in our <details-utils> web component. Mix and match these utilities as needed:

  • Click outside to close
  • Animate open and close
  • Force State
  • Close by esc key
  • Toggle document class
